The Go Cheat Sheet

Syntax, idioms and the standard library on one page. Every card is runnable-style code you can lift straight into a file. Filter to find a card fast.

    Zero values are useful

    Every type has a ready default: 0, "", false, nil. A zero sync.Mutex or bytes.Buffer works without setup.

    Errors are values

    No exceptions. Functions return error last; callers check if err != nil and wrap with %w.

    Implicit interfaces

    A type satisfies an interface by having the methods. No implements keyword. Keep interfaces small and define them where they are used.

    Composition, not inheritance

    No classes. Structs embed other structs; methods and fields are promoted to the outer type.

    Share by communicating

    Goroutines are cheap. Pass data over channels; reach for sync.Mutex when guarding shared state is simpler.

    Capital = exported

    User is public outside the package; user is private. That is the whole visibility system.

    One format

    gofmt settles style. Unused imports and variables are compile errors, so code stays tidy.

    Static binaries

    go build produces one file. Cross-compile with GOOS=linux GOARCH=arm64 go build.

    Basics

    Program shape, variables, types

    Program skeleton

    Executables live in package main and start at func main().

    Variables

    := declares and infers, only inside functions.

    Constants & iota

    iota counts up from 0 inside a const block.

    Basic types

    Sizes are explicit; int is 64-bit on 64-bit platforms.

    Conversions

    No implicit numeric conversion. Use strconv for text ↔ numbers.

    Pointers

    & takes an address, * dereferences. No pointer arithmetic.

    Control flow

    if, for, switch, defer

    if with init

    The init statement's variables are scoped to the if/else.

    for: the only loop

    Three-part, condition-only (while), and infinite.

    range

    Works on slices, arrays, strings, maps, channels, ints and iterator funcs.

    switch

    No fallthrough by default. Cases can list values or be bare conditions.

    defer

    Runs when the function returns, in LIFO order. Arguments are evaluated immediately.

    Functions & methods

    Returns, closures, receivers

    Multiple & named returns

    The error goes last by convention.

    Variadic & function values

    Functions are first-class: pass them, return them, store them.

    Closures

    Inner functions capture variables by reference.

    Methods & receivers

    Use a pointer receiver to mutate or to avoid copying large structs. Be consistent per type.

    Slices, maps & strings

    The everyday data structures

    Arrays vs slices

    Arrays have a fixed size in their type. Slices are views onto an array.

    Slice header

    A slice is three words: pointer, length, capacity. s[1:3] points into the same backing array.

    slices package

    Generic helpers in the standard library since Go 1.21.

    Maps

    Use the comma-ok form to tell "missing" from "zero value".

    Strings, bytes & runes

    Strings are immutable UTF-8 bytes. len counts bytes, not characters.

    strings package

    The functions you reach for daily.

    Structs & interfaces

    Data, behavior, composition

    Structs

    Construct with field names; omitted fields get zero values. NewX functions act as constructors.

    Struct tags & JSON

    Tags are metadata read by packages like encoding/json.

    Embedding

    The embedded type's fields and methods are promoted to the outer type.

    Interfaces

    Satisfied implicitly. Accept interfaces, return concrete types.

    Type assertions & switches

    any is an alias for interface{}.

    Generics

    Type parameters, Go 1.18+

    Generic functions

    Type parameters go in square brackets. Types are usually inferred.

    Constraints

    ~T means "any type whose underlying type is T".

    Generic types

    Methods use the type's parameters but cannot add new ones.

    Iterators 1.23+

    Range over a function that yields values. iter.Seq is the standard shape.

    Error handling

    Check, wrap, inspect

    Check and wrap

    %w wraps the cause so callers can still inspect it.

    Sentinels, Is & As

    errors.Is matches a value; errors.As extracts a type. Both walk the wrap chain.

    Custom error types

    Any type with Error() string is an error.

    panic & recover

    Reserve panic for programmer bugs. recover works only inside a deferred function.

    Concurrency

    Goroutines, channels, sync, context

    Goroutines & WaitGroup

    go f() starts a goroutine. A WaitGroup waits for a batch to finish.

    Channels

    Unbuffered sends block until received. Only the sender should close.

    Pipeline pattern

    Stages connected by channels; each stage owns and closes its output.

    Worker pool

    Fixed number of goroutines draining a jobs channel.

    select

    Waits on several channel operations; default makes it non-blocking.

    Mutex & atomics

    Guard shared state. RWMutex allows many readers at once.

    context

    Carries deadlines and cancellation across API boundaries. Pass it as the first argument.

    errgroup

    From golang.org/x/sync: run tasks, return the first error, cancel the rest.

    fmt, files, time, HTTP, logging

    Files & I/O

    Read whole files for small data; stream with bufio for large ones.

    time

    Layouts use the reference time Mon Jan 2 15:04:05 MST 2006.

    HTTP server 1.22+

    The standard mux supports methods and path wildcards.

    HTTP client

    Always close the body and set a timeout.

    Middleware

    A function that wraps a http.Handler.

    Structured logging

    log/slog ships in the standard library since 1.21.

    CLI flags & env

    The flag package covers most small tools.

    Modules, testing & tools

    Project layout

    A common shape. internal/ cannot be imported from outside the module.

    Table-driven tests

    Files end in _test.go; functions start with Test.

    Benchmarks & helpers

    Run with go test -bench=. -benchmem.

    Gotchas

    Mistakes the compiler won't catch

    Writing to a nil map

    Reading a nil map is fine; writing panics.

    Nil interface that isn't nil

    An interface holding a typed nil pointer is not equal to nil.

    Slice aliasing

    append may write into a shared backing array.

    Goroutine leaks

    A goroutine blocked on a channel nobody reads lives forever.

    Map iteration & concurrency

    Order is randomized, and maps are not safe for concurrent writes.

    defer in loops

    Deferred calls wait for the function, not the iteration.
