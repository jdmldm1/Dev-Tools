Troubleshooting pod status → what to run

get pods→describe pod→logs (--previous)→get events→exec / debug
StatusUsual causeCheck with
PendingNo node fits: CPU/memory requests, taints, nodeSelector, or an unbound PVCkubectl describe pod <p> → Events
ImagePullBackOffWrong image name or tag, private registry without imagePullSecretskubectl describe pod <p>
CrashLoopBackOffApp exits on start: bad config, missing env, failing commandkubectl logs <p> --previous
OOMKilledContainer went over its memory limitkubectl describe pod → Last State; kubectl top pod
CreateContainerConfigErrorReferenced ConfigMap or Secret key is missingkubectl get cm,secret
Running, 0/1 ReadyReadiness probe failing; Service sends no traffickubectl describe pod; kubectl get endpoints <svc>
Terminating (stuck)Finalizer or unreachable nodekubectl get pod <p> -o yaml | grep -A3 finalizers
CompletedNormal for Job/CronJob podskubectl logs job/<job>
